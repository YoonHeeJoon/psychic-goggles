# STARWIND · 별바람 군도

Three.js로 만든 **원신 스타일 오픈월드 액션 RPG**입니다. 셀 셰이딩 캐릭터, 바람에 흔들리는 풀밭,
흐르는 구름과 낮밤 주기, 활공·등반·수영까지 — 원신의 감성을 목표로 처음부터 직접 만들었습니다.

> 모든 캐릭터, 지역, 아트는 오리지널 창작물입니다. (원신의 에셋·이름·로고는 사용하지 않습니다.)

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/
npm run build:single # dist-single/index.html (파일 하나로 실행 가능)
npm run build:artifact # dist-artifact/starwind.html (three.js는 jsDelivr에서 로드)
```

플레이 링크(비공개 아티팩트): https://claude.ai/artifact/6eySxz6tjyPu4qDnhcLvPE

품질은 시작 화면·설정 메뉴에서 바로 바꿀 수 있고(새로고침 없음), 개발 중에는 `?q=low|medium|high|ultra` 도 쓸 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD | 이동 |
| Shift / 우클릭 | 질주 (스태미나 소모) |
| Space | 점프 · 공중에서 다시 누르면 활공 · 등반 중 도약 |
| 절벽 쪽으로 이동 | 등반 시작 · X 로 손 놓기 |
| 마우스 / 휠 | 시점 회전 / 줌 |
| 좌클릭 | 일반 공격 (연타 시 콤보) · 공중/활공 중이면 낙하 공격 |
| E | 원소 전투 스킬 |
| Q | 원소 폭발 (에너지가 가득 찼을 때) |
| 1 – 4 | 파티 캐릭터 교체 |
| F | 상호작용 (대화, 채집, 요리, 보물상자 열기, 순간이동 포인트 활성화, 수호상에 기도) |
| B | 가방 (재료·요리 확인, 요리 먹기) |
| C | 캐릭터 (레벨 업, 특성 강화) |
| L | 모험 기록 (업적) |
| P | 사진 모드 (드래그 회전 · 휠 거리 · 필터 · 포즈 · 시간, Space 촬영) |
| M | 지도 (드래그·휠로 이동/확대, 순간이동 포인트를 눌러 이동) |
| Ctrl | 걷기 토글 |
| Esc | 설정 메뉴 (품질, 감도, 소리, 날씨, 시간대, 자동 해상도) |

모든 키는 설정 메뉴의 **조작 키 설정**에서 바꿀 수 있습니다.

**게임패드**: 왼쪽 스틱 이동 · 오른쪽 스틱 시점 · A 점프 · B 질주 · X 공격 · Y 상호작용 · RB 원소 스킬 · RT 원소 폭발 ·
십자키 캐릭터 교체 · LT 가방 · View 지도 · Menu 일시정지 (메뉴에서는 A 확인, B 닫기)

**터치(휴대폰·태블릿)**: 왼쪽 화면을 끌면 가상 조이스틱, 오른쪽을 끌면 시점 회전. 공격·E·Q·점프·질주 버튼,
초상화를 눌러 캐릭터 교체, 상호작용 표시를 눌러 F, 상단 `지도`·`메뉴` 버튼. 터치 기기에서 자동으로 켜지고 `?touch=1` 로 강제할 수 있습니다.

## 구현된 것

- **렌더링**: 커스텀 툰 셰이더(2톤 램프·색조 그림자·림 라이트·외곽선), 블룸, 컬러 그레이딩, MSAA, 플레이어를 따라가는 그림자맵,
  화면 공간 빛줄기(구름·나뭇잎 틈으로 쏟아지는 햇살, 해가 낮을수록 강하게 · 밤에는 은은한 달빛),
  툰 셰이딩에 맞춘 앰비언트 오클루전(집 밑동·처마·소품 주위에 푸른빛 그림자가 고이고, 캐릭터 얼굴은 깨끗하게 유지),
  땅 위를 흘러가는 구름 그림자, 새벽 골짜기에 깔리는 높이 안개(햇빛을 받아 빛나고 바람에 흘러감)
- **원경**: 섬 너머 세 겹의 먼 산맥과 바다 위 바위섬(대기 원근감, 햇빛 받는 능선, 눈 덮인 봉우리)
- **캐릭터 셰이딩**: 머리카락 '천사의 고리' 하이라이트(시점에 따라 이동, 머리끝 모양으로 들쭉날쭉),
  얼굴 전용 그림자(빛 방향에 따라 경계선이 얼굴을 가로지르는 애니메식 음영, 코 그림자), 대기 동작(두리번·기지개·짝다리·발장난)
- **월드**: 절차적 섬 지형(초원·메사 절벽·설산·호수·해변·흙길), 삼면 투영 보로노이 암석, 눈 덮인 산봉우리
- **식생**: GPU 인스턴싱 풀(최대 32만 포기) — 바람 물결, 캐릭터가 지나가면 눕는 풀, 나뭇잎 카드 나무, 침엽수, 덤불, 꽃, 바위, 거대한 천년나무
- **하늘**: 낮/밤 주기, 해·달·별, 2층 구름(높은 층 + 지평선 적운), 대기 안개
- **물**: 호수 바닥이 비치는 굴절(빛이 물을 지나며 색마다 다르게 흡수 — 얕은 곳은 투명한 청록, 깊은 곳은 짙은 파랑),
  바닥에 일렁이는 코스틱, 해변으로 밀려오는 파도 줄, 바위·다리·물에 선 다리 주위 포말, 수영하면 뒤로 퍼지는 물살,
  천천히 오르내리는 물가, 프레넬 반사와 햇빛 반짝임
- **캐릭터**: 절차적으로 만든 애니메 캐릭터 4명(얼굴 텍스처, 머리카락 가닥, 의상), 눈 깜빡임,
  머리카락·포니테일·망토·치마·스카프가 사슬처럼 휘는 물리(달리면 뒤로 날리고 멈추면 앞으로 휘청, 돌면 바깥으로 쏠리고 활공 중엔 펄럭임)
- **발자국**: 모래와 눈 위에 발자국이 남고 30초에 걸쳐 사라짐
- **이동**: 달리기·질주·점프·활공·등반·수영, 스태미나, 낙하 피해, 익사 후 리스폰
- **전투**: 무기별 콤보(한손검·양손검·장병기·법구), 검기 잔상, 히트 스톱, 낙하 공격, 질주 회피
- **원소**: 캐릭터별 원소 스킬·원소 폭발, 원소 입자로 에너지 충전, 원소 반응 7종(증발·융해·과부하·빙결·감전·초전도·확산, 쇄빙)
- **적**: 원소 슬라임 5종(자기 원소 면역)과 가면 고블린, 추적·도약 공격·곤봉 공격 AI, 처치 시 별빛 결정 드랍, 재등장
- **탐험**: 순간이동 포인트 7곳, 날개 달린 바람의 수호상(기도하면 회복, 별바람의 눈을 바치면 최대 기력 증가),
  풍차 마을(목조 골조 집, 돌아가는 풍차, 광장·우물·노점·깃발 장식, 밤이면 켜지는 창문과 가로등), 숲속 잊힌 유적(룬이 빛나는 고리 석상)
- **수집**: 높은 곳마다 숨겨진 별바람의 눈 27개(근처에서 미니맵에 공명), 보물상자 14개(평범·정교·진귀, 몬스터를 처치하면 풀리는 봉인 상자)
- **상승 기류**: 들어가면 자동으로 글라이더가 펼쳐지며 하늘로 떠오름 — 설산, 천년나무, 유적으로 가는 지름길
- **구조물 등반**: 집 벽, 풍차, 수호상도 절벽처럼 오르고 지붕 위에 설 수 있음
- **지도**: 직접 그린 듯한 전체 지도(등고선·음영·도로·지붕), 지역 이름, 탐험 진행도, 순간이동
- **저장**: 진행 상황(수집품·상자·순간이동 포인트·결정)은 브라우저에 자동 저장 (`?fresh` 로 새로 시작)
- **마을 사람들**: 촌장·요리사·상인·풍차지기·아이 5명 — 저마다 동선을 따라 움직이고, 가까이 가면 돌아보며 말풍선으로 혼잣말을 함.
  대화창(이름·타자 효과·오른쪽 선택지)과 어깨 너머 대화 카메라, 상인에게 별빛 결정으로 재료 구입
- **임무 「바람이 머무는 마을」**: 촌장과 대화 → 수호상에 기도 → 바람방울꽃 3송이 채집 → 요리사에게 전달 → 잊힌 유적 고리 석상 조사 → 보고.
  화면 왼쪽 임무 추적, 화면 가장자리까지 따라오는 목표 표시, 미니맵 테두리 표시, 보상
- **채집·요리**: 바람방울꽃·노을사과·달빛버섯(밤에 빛남)·별딸기가 섬 곳곳에서 반짝이고 몇 분 뒤 다시 자람.
  가방(B), 마을·야영지 요리 솥에서 요리 4종(HP 회복, 공격력 증가, 기력 소모 감소)
- **날씨**: 지나가는 소나기(회색 하늘, 빗줄기, 땅·지붕이 젖고 웅덩이에 하늘이 비침, 호수에 빗방울 파문), 비가 그치면 무지개,
  밤에는 번개와 천둥이 치는 뇌우. 설정에서 자동/맑음/비/뇌우 선택
- **야생동물**: 꽃 주변을 나는 나비, 흙길·해변에서 모이를 쪼다 다가가면 날아오르는 새 떼, 해안을 맴도는 갈매기,
  호수 속을 헤엄치다 가끔 뛰어오르는 물고기, 밤 풀밭의 반딧불이
- **보스 「뇌광의 결정체 · 아르크」**: 동쪽 절벽 위 결전장에 잠든 폭풍 결정체. 들어서면 등장 연출과 이름 카드,
  화면 위 보스 HP 바. 8개의 파편이 조각 비·조준 광선(2단계에서 두 줄기)·낙하 기둥·바닥 충격파로 변하고 바닥에 위험 범위가 표시됨.
  HP 50%에서 번개 방어막과 소환 슬라임 — 원소 반응으로 방어막을 깨면 기절, 이후 더 빠른 2단계. 처치하면 진귀한 보물상자, 일정 시간 뒤 재도전
- **비경 「바람 그림자 회랑」**: 입구의 소용돌이 포탈로 북쪽 바다 위 공중 신전에 들어가 소개 연출 → 카운트다운 →
  150초 안에 몬스터 3파 처치. 성공하면 보상 상자와 첫 클리어 보너스, 출구 포탈로 귀환
- **퍼즐**: 잊힌 유적의 꺼진 화로 4개(불로 켜고 물로 꺼짐, 시간이 지나면 꺼짐), 초원 길가 바람개비 3개(바람으로 동시에 돌리기),
  상승 기류를 타는 시간 제한 '바람길 도전' — 풀면 보물상자가 나타남
- **성장**: 별빛 결정으로 캐릭터 레벨 업(최대 50, HP·공격력·받는 피해 감소)과 원소 스킬·폭발 특성 강화(최대 8).
  피해는 캐릭터와 적의 레벨 차이에 따라 달라지고, 적은 초원에서 멀어질수록 강해짐 (Lv.15~34)
- **연출**: 원소 폭발 컷인(카메라가 캐릭터 얼굴로 돌아가며 원소 색 띠와 초상화가 지나감), 캐릭터 교체 빛기둥과 등장 바운스,
  카메라가 집·나무에 부딪히면 앞으로 당겨지고 카메라 바로 앞 나뭇잎은 점묘식으로 투명해짐
- **음악**: 낮(F장조 플루트·하프·현악), 밤(A단조 느린 하프), 전투(D단조 현악 스타카토·드럼), 보스(C단조 태고 드럼·저음)를
  실시간으로 작곡·연주하고 상황에 따라 교차 전환. 탐험 음악은 한 구절 연주 후 쉬어 감
- **모험 기록**: 업적 18개(처치·보물·별바람의 눈·순간이동·원소 반응·채집·요리·임무·퍼즐·보스·비경·활공·정상·성장·사진),
  달성하면 알림과 별빛 결정 보상
- **사진 모드**: HUD를 숨기고 자유 카메라, 필터 6종, 포즈, 시간대, PNG 저장
- **소리**: 음원 파일 없이 Web Audio로 실시간 합성 — 고도·속도에 따라 변하는 바람, 숲의 나뭇잎, 파도, 낮의 새소리, 밤의 귀뚜라미,
  지면별 발소리(풀·흙길·모래·돌·나무·눈·물), 무기 휘두르기·타격·원소 스킬·폭발·반응음, 상자·별바람의 눈·순간이동 포인트 효과음, UI 클릭
- **성능**: 식생을 구역별 인스턴스로 나눠 시야·그림자 절두체 컬링(삼각형 약 40~50% 감소), 작은 소품 거리 컬링,
  멀리 있는 적의 외곽선·그림자 생략, 프레임이 떨어지면 렌더 해상도를 자동 조절
- **UI**: 미니맵(적·순간이동 포인트·수호상 표시), 파티 초상화, HP, 스킬 쿨타임·에너지 링, 데미지 숫자, 적 HP 바와 원소 부착 아이콘, 스태미나 링, 지역 배너, 설정 메뉴

### 파티

| 캐릭터 | 원소 · 무기 | 원소 스킬 (E) | 원소 폭발 (Q) |
| --- | --- | --- | --- |
| 아리아 | 바람 · 한손검 | 회오리 베기: 주변 적을 끌어당기고 띄움 | 폭풍의 눈: 원소를 흡수하는 거대 회오리 |
| 렌 | 불 · 양손검 | 화염 돌진: 돌진 후 폭발 | 불새의 낙인: 도약 내려찍기 + 불타는 대지 |
| 미즈하 | 물 · 법구 | 물방울 결계: 회복 + 주위를 도는 물방울 | 해명의 비: 범위 비, 지속 피해와 회복 |
| 라이카 | 번개 · 장병기 | 뇌전 낙인: 가까운 적 3명에게 낙뢰 | 천뢰: 회전 베기 + 낙뢰 폭풍 |
