# 슬라임 서바이버

밀려오는 슬라임 군단 속에서 **10분간 살아남는** 서바이버 로그라이트 게임입니다.
이동만 직접 하고, 공격은 자동! 레벨업할 때마다 3개 중 하나를 골라 강해집니다.

## 실행

빌드나 설치 없이 `index.html` 파일 하나로 동작합니다. 브라우저에서 파일을 열기만 하면 됩니다.

```sh
# 또는 로컬 서버로 실행
python3 -m http.server 8000   # → http://localhost:8000
```

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| 화면 드래그 (터치·마우스) | 가상 조이스틱으로 이동 |
| `1` `2` `3` | 레벨업 선택지 고르기 |
| `P` / `Esc` | 일시정지 |
| `M` | 소리 켜기/끄기 |
| `Enter` / `Space` / `R` | 시작 · 재시작 |

## 게임 요소

**무기** (최대 Lv 5)
- 🏹 마법 화살 — 가장 가까운 적에게 자동 발사, 관통 강화 가능
- 🔮 수호 구슬 — 몸 주위를 도는 구슬
- 💥 충격파 — 주기적으로 주변을 날려버리는 범위 공격
- ⚡ 번개 — 화면 속 무작위 적에게 낙뢰

**패시브** (최대 Lv 5): ❤️ 강인함 · 👟 질풍 · 🧲 자석 · 💪 괴력 · ⏱️ 집중 · 🍀 재생

**적**: 슬라임 → 박쥐(40초~) → 브루트(1분 30초~) → 유령(2분 30초~)
45초마다 몬스터 떼가 포위해 오고, 2분마다 보스가 등장합니다. 10분을 버티면 승리!

## 구조

- `index.html` — 게임 전체 (HTML + CSS + JS, 외부 의존성 없음)
- 최고 기록은 브라우저 `localStorage`에 저장됩니다.
- 개발용 훅 `window.__survivor` 를 통해 헤드리스 브라우저에서 시뮬레이션/테스트할 수 있습니다.
