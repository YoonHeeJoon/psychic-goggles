# STARWIND · 별바람 군도

Three.js로 만든 **원신 스타일 오픈월드 액션 RPG**입니다. 셀 셰이딩 캐릭터, 바람에 흔들리는 풀밭,
흐르는 구름과 낮밤 주기, 활공·등반·수영까지 — 원신의 감성을 목표로 처음부터 직접 만들었습니다.

> 모든 캐릭터, 지역, 아트는 오리지널 창작물입니다. (원신의 에셋·이름·로고는 사용하지 않습니다.)

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/
npm run build:single # dist-single/index.html (파일 하나로 실행 가능)
npm run build:artifact # dist-artifact/starwind.html (three.js는 jsDelivr에서 로드)
```

플레이 링크(비공개 아티팩트): https://claude.ai/artifact/6eySxz6tjyPu4qDnhcLvPE

품질은 시작 화면·설정 메뉴에서 바로 바꿀 수 있고(새로고침 없음), 개발 중에는 `?q=low|medium|high|ultra` 도 쓸 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD | 이동 |
| Shift / 우클릭 | 질주 (스태미나 소모) |
| Space | 점프 · 공중에서 다시 누르면 활공 · 등반 중 도약 |
| 절벽 쪽으로 이동 | 등반 시작 · X 로 손 놓기 |
| 마우스 / 휠 | 시점 회전 / 줌 |
| 좌클릭 | 일반 공격 (연타 시 콤보) · 공중/활공 중이면 낙하 공격 |
| E | 원소 전투 스킬 |
| Q | 원소 폭발 (에너지가 가득 찼을 때) |
| 1 – 4 | 파티 캐릭터 교체 |
| F | 상호작용 (보물상자 열기, 순간이동 포인트 활성화, 수호상에 기도) |
| M | 지도 (드래그·휠로 이동/확대, 순간이동 포인트를 눌러 이동) |
| Ctrl | 걷기 토글 |
| Esc | 설정 메뉴 (품질, 감도, 소리, 시간대, 자동 해상도) |

**터치(휴대폰·태블릿)**: 왼쪽 화면을 끌면 가상 조이스틱, 오른쪽을 끌면 시점 회전. 공격·E·Q·점프·질주 버튼,
초상화를 눌러 캐릭터 교체, 상호작용 표시를 눌러 F, 상단 `지도`·`메뉴` 버튼. 터치 기기에서 자동으로 켜지고 `?touch=1` 로 강제할 수 있습니다.

## 구현된 것

- **렌더링**: 커스텀 툰 셰이더(2톤 램프·색조 그림자·림 라이트·외곽선), 블룸, 컬러 그레이딩, MSAA, 플레이어를 따라가는 그림자맵,
  화면 공간 빛줄기(구름·나뭇잎 틈으로 쏟아지는 햇살, 해가 낮을수록 강하게 · 밤에는 은은한 달빛)
- **원경**: 섬 너머 세 겹의 먼 산맥과 바다 위 바위섬(대기 원근감, 햇빛 받는 능선, 눈 덮인 봉우리)
- **캐릭터 셰이딩**: 머리카락 '천사의 고리' 하이라이트(시점에 따라 이동, 머리끝 모양으로 들쭉날쭉),
  얼굴 전용 그림자(빛 방향에 따라 경계선이 얼굴을 가로지르는 애니메식 음영, 코 그림자), 대기 동작(두리번·기지개·짝다리·발장난)
- **월드**: 절차적 섬 지형(초원·메사 절벽·설산·호수·해변·흙길), 삼면 투영 보로노이 암석, 눈 덮인 산봉우리
- **식생**: GPU 인스턴싱 풀(최대 32만 포기) — 바람 물결, 캐릭터가 지나가면 눕는 풀, 나뭇잎 카드 나무, 침엽수, 덤불, 꽃, 바위, 거대한 천년나무
- **하늘**: 낮/밤 주기, 해·달·별, 2층 구름(높은 층 + 지평선 적운), 대기 안개
- **물**: 깊이에 따른 색, 프레넬 반사, 햇빛 반짝임, 해안 포말, 코스틱
- **캐릭터**: 절차적으로 만든 애니메 캐릭터 4명(얼굴 텍스처, 머리카락 가닥, 의상), 머리·치마·망토 2차 모션, 눈 깜빡임
- **이동**: 달리기·질주·점프·활공·등반·수영, 스태미나, 낙하 피해, 익사 후 리스폰
- **전투**: 무기별 콤보(한손검·양손검·장병기·법구), 검기 잔상, 히트 스톱, 낙하 공격, 질주 회피
- **원소**: 캐릭터별 원소 스킬·원소 폭발, 원소 입자로 에너지 충전, 원소 반응 7종(증발·융해·과부하·빙결·감전·초전도·확산, 쇄빙)
- **적**: 원소 슬라임 5종(자기 원소 면역)과 가면 고블린, 추적·도약 공격·곤봉 공격 AI, 처치 시 별빛 결정 드랍, 재등장
- **탐험**: 순간이동 포인트 7곳, 날개 달린 바람의 수호상(기도하면 회복, 별바람의 눈을 바치면 최대 기력 증가),
  풍차 마을(목조 골조 집, 돌아가는 풍차, 광장·우물·노점·깃발 장식, 밤이면 켜지는 창문과 가로등), 숲속 잊힌 유적(룬이 빛나는 고리 석상)
- **수집**: 높은 곳마다 숨겨진 별바람의 눈 27개(근처에서 미니맵에 공명), 보물상자 14개(평범·정교·진귀, 몬스터를 처치하면 풀리는 봉인 상자)
- **상승 기류**: 들어가면 자동으로 글라이더가 펼쳐지며 하늘로 떠오름 — 설산, 천년나무, 유적으로 가는 지름길
- **구조물 등반**: 집 벽, 풍차, 수호상도 절벽처럼 오르고 지붕 위에 설 수 있음
- **지도**: 직접 그린 듯한 전체 지도(등고선·음영·도로·지붕), 지역 이름, 탐험 진행도, 순간이동
- **저장**: 진행 상황(수집품·상자·순간이동 포인트·결정)은 브라우저에 자동 저장 (`?fresh` 로 새로 시작)
- **소리**: 음원 파일 없이 Web Audio로 실시간 합성 — 고도·속도에 따라 변하는 바람, 숲의 나뭇잎, 파도, 낮의 새소리, 밤의 귀뚜라미,
  지면별 발소리(풀·흙길·돌·나무·눈·물), 무기 휘두르기·타격·원소 스킬·폭발·반응음, 상자·별바람의 눈·순간이동 포인트 효과음, UI 클릭
- **성능**: 식생을 구역별 인스턴스로 나눠 시야·그림자 절두체 컬링(삼각형 약 40~50% 감소), 작은 소품 거리 컬링,
  멀리 있는 적의 외곽선·그림자 생략, 프레임이 떨어지면 렌더 해상도를 자동 조절
- **UI**: 미니맵(적·순간이동 포인트·수호상 표시), 파티 초상화, HP, 스킬 쿨타임·에너지 링, 데미지 숫자, 적 HP 바와 원소 부착 아이콘, 스태미나 링, 지역 배너, 설정 메뉴

### 파티

| 캐릭터 | 원소 · 무기 | 원소 스킬 (E) | 원소 폭발 (Q) |
| --- | --- | --- | --- |
| 아리아 | 바람 · 한손검 | 회오리 베기: 주변 적을 끌어당기고 띄움 | 폭풍의 눈: 원소를 흡수하는 거대 회오리 |
| 렌 | 불 · 양손검 | 화염 돌진: 돌진 후 폭발 | 불새의 낙인: 도약 내려찍기 + 불타는 대지 |
| 미즈하 | 물 · 법구 | 물방울 결계: 회복 + 주위를 도는 물방울 | 해명의 비: 범위 비, 지속 피해와 회복 |
| 라이카 | 번개 · 장병기 | 뇌전 낙인: 가까운 적 3명에게 낙뢰 | 천뢰: 회전 베기 + 낙뢰 폭풍 |
